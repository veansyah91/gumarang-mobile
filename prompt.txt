## HTTP Status Codes

| Code | Meaning |
|------|---------|
| 200  | OK - Request berhasil |
| 401  | Unauthorized - Token tidak valid/expired |
| 403  | Forbidden - Invoice tidak ditemukan atau bukan milik user |
| 500  | Internal Server Error - Error server |
